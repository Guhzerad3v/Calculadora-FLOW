# Calculadora-FLOW

Trabalho prático desenvolvido para a matéria de Algoritmos e Lógica de Programação. O objetivo foi criar uma calculadora com menu interativo utilizando fluxograma no software Flowgorithm.

### O que o programa faz:
O usuário escolhe uma opção digitando o número correspondente no menu:

* `1` - Somar
* `2` - Subtrair
* `3` - Multiplicar
* `4` - Dividir
* `5` - Potenciação
* `6` - Raiz Quadrada
* `7` - Área do Triângulo
* `8` - Área da Circunferência
* `9` - Conversão para Fahrenheit
* `10` - Cálculo de IMC
* `11` - Encerrar Programa

### Como rodar:
1. Precisa ter o Flowgorithm instalado no computador.
2. Baixar o arquivo `.fprg` aqui do repositório.
3. Abrir o arquivo no programa e clicar no botão Executar (Play / F5).
